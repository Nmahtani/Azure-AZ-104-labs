# Azure AZ-104 Labs

## Labs for Azure Administrator Associate (AZ-104)

Welcome to my Azure AZ-104 Enterprise Labs repository.

This repository contains hands-on labs, real-world simulations, and infrastructure deployment exercises focused on Microsoft Azure administration and cloud operations.

The goal of these labs is to strengthen practical Azure skills by building and managing enterprise-style environments using Azure services, automation, networking, identity, governance, and virtual infrastructure.

---

## 🎯 Objectives

These labs simulate real-world Azure administration scenarios commonly found in enterprise IT environments, including:

- Deploying and managing Azure Virtual Machines  
- Configuring Virtual Networks and Network Security Groups  
- Managing Microsoft Entra ID (Azure Active Directory)  
- Implementing Role-Based Access Control (RBAC)  
- Automating deployments using Bicep and ARM templates  
- Configuring storage accounts and backup solutions  
- Monitoring resources with Azure Monitor and Log Analytics  
- Managing identities, permissions, and security policies  
- Implementing hybrid and cloud infrastructure concepts  
- Troubleshooting connectivity and infrastructure issues
